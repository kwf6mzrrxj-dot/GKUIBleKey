## 二、问题清单（按严重程度）

### R4-1 · P1 · `Text(timerInterval:)` 的 `ClosedRange` 可能崩溃

**位置**：`Sources/UI/RootView.swift:1357`（点火按钮的第三行）

**成因**：

```swift
if let end = model.unlockWindowEndsAt, end > Date() {
    Text(timerInterval: Date()...end, countsDown: true)   // ← 第二次取 Date()
}
```

判断用一次 `Date()`、构造 Range 又用一次。`ClosedRange(lowerBound:upperBound:)`
要求 `lowerBound <= upperBound`，否则**直接 `fatalError`**（不是返回 nil）。
如果 `end` 恰好落在两次调用之间 —— 也就是解锁授权到期的那一帧 —— App 会崩在渲染里。

**影响**：低概率但必现的一帧。点火授权窗口约 5 分钟，用户在那 1ms 内刷新 UI 就会触发。

**修复**：判断与构造共用同一个 `now`。

```swift
let now = Date()
if let end = model.unlockWindowEndsAt, end > now {
    Text(timerInterval: now...end, countsDown: true)
}
```

### R4-2 · P2 · 六个设计令牌零引用，文档与实现不符

**位置**：`Sources/UI/DesignSystem.swift`

**成因**：上一轮为了"建立规范"定义了 `Typo` / `Tone` / `rimStroke` / `GlassSection` /
`innerSpacing` / `sectionSpacing`，但**一个都没被调用**。文档写着"唯一来源"，
代码里所有地方仍在写裸数值。

这是本轮最值得记的一条：**规范不是写出来的，是被引用出来的**。
定义了不用，比不定义更糟 —— 下一个人会以为它在生效，改令牌却没效果。

**影响**：改一处令牌不会影响任何界面，等于假的单一来源。

**修复**：
- 落地：`Typo.cardTitle`(4) / `Typo.page`(2) / `Typo.body`(1) / `Typo.micro`(2) /
  `Tone.*`(6) / `innerSpacing`(4) / `sectionSpacing`(5)
- 删除：`Typo.caption`（就是 `Font.caption`，无信息量）、`rimStroke`（系统材质自带高光）、
  `GlassSection`（零引用，真实融合场景未出现）

### R4-4 · P2 · 同一个状态胶囊内两种字号

**位置**：`Sources/UI/RootView.swift:380, 395`

**成因**：胶囊第一行 12pt、第二行 9.5pt、第三行 9.5pt，而别的次要信息是 9pt。

读者会觉得"这里好像有点不一样，说不上来"。

**修复**：统一到 `Glass.Typo.micro`(9)。至此全项目不再有 9.5pt。

## 四、UI 评估

### 布局一致性 ✅

- **形状体系**：主操作圆角矩形（20）、次要操作胶囊、卡片圆角矩形（20/14）、
  角标（12/6）—— 四档覆盖全部，无第五种。
- **导航层级**：主界面自绘 22pt 左对齐标题；二级页系统 inline 17pt 居中。
  这是**主/次层级**，不是不一致 —— 强行统一会让二级页失去返回手势。
- **网格**：控制区 2 个主按钮 + 8 个次要按钮（3 列，最后一行 2 个）。
  右下角空一格是等宽排布的必然结果；用变宽去填会破坏"尺寸一致"，故保留。

### 交互可用性 ⚠️

- ✅ 能点的按钮不画成不能点（不按连接状态调 opacity），状态由顶栏胶囊表达
- ✅ 误触代价高的动作有长按 + 进度反馈
- ✅ 「启动引擎」标签固定，运行态在第三行显示，点击时弹明确写"熄火"的确认框
- ⚠️ 控制区共 10 个按钮，一屏内信息密度偏高。「点火 / 启动引擎」并入网格后
  密度进一步上升 —— 若后续再加动作，需要重新考虑分组（折叠或分页）
- ❌ 靠近解锁的运行状态只在「密钥」第三层可见（P3 遗留，状态页已有只读卡片，
  但控制页没有）

### 响应式 ⚠️

- ✅ 锁竖屏 + iPhone only；网格 `GridItem(.flexible())` 自适应；刻度带 `GeometryReader`
- ⚠️ 未在 SE 尺寸（375pt）验证：8 个按钮的"启动引擎"4 字 + 网络角标在最小列宽下
  需要 `minimumScaleFactor` 兜底（已加 0.8）
- ❌ 深色模式未真机确认

### 视觉规范 ✅
