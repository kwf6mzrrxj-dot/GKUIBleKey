#  用法：把本文件复制为 `builtin-keys.txt`（同一目录），填入真实值。
#        该文件被 .gitignore 排除，不会被提交。
#
#  格式：每行 key=value，# 开头为注释。值一律 hex，小写。
#
#  字段来源：原 App Keychain 的 IBSavedKeys（iOS 加密备份 →
#  keychain-backup.plist → genp 条目 → v_Data 解密）。
#  其中 dk1 / rndTRx 每把钥匙独立，其余为车端级常量。
#
#  ⚠️ 不填也能编译运行：BuiltInKeys.isConfigured == false 时
#     自动跳过写入，走「自己配对」的正常路径。
# ============================================================
